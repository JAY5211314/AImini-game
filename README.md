# AImini-game
使用AI制作简单小游戏展示。Create a simple game demonstration using AI.

# Making process
Simply hand over the Readme.txt file in the game folder to Cursor, asking it to create an HTML-written game. If there are any issues during the testing process, just let it correct them. Based on the Audio files it generated, I added some music. The total production time for the final product was less than one hour.直接将游戏文件夹中的Readme.txt交给Cursor让其生成一个HTML写的游戏，运行测试有问题直接让它改正即可，并根据它生成的Audio文件，我添加了一个音乐。最终成品制作时长总共不到1小时。

# Duration proportion
Plan the gameplay 20%
AI-generated 20%
Testing game 50%
Search for audio 10%
